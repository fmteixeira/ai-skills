---
name: skill-writing
description: Use whenever asked to write, draft, edit or turn something into a skill. How skills here are written, and that their contents get signed off before being added.
---

Write skills short and light. Often close to how the user said it, almost verbatim.

Agents running a skill are very smart and don't need strict guidance. Tight language can accidentally over-restrict them, and a skill is less useful when it's too specific.

Prefer soft phrasing: "consider", "often", "may", "look out for". Say what matters and trust the agent with the rest.

Write less. If a line only explains or justifies another line, it can usually go.

Suggest the contents and get them signed off by the user before adding the skill.
